# 2.3.0 — 安全优先的语法诊断层

2.3.0 把 EpXsC 的语法问题放到阅读/Live Preview 中可见的位置，并保留 2.2.0 的可选翻译能力。

## 新增

- D1：lint issue 带 line/column/start/end；括号与未登记单位为精确范围；CRLF fixture。
- D2：EpXsC 块红色/橙色诊断线；T/G 未入典词点线；更大、可点击的自定义 tooltip。
- 桌面状态栏错误/警告计数；点击打开 lint 面板。
- diagnostics.enabled 总开关，默认开启；editorDecorations 为 2.3.x 预留，默认关闭。
- 2.2.0 的可选 OpenAI-compatible 翻译、作者参考、隐私脱敏一并包含。

## 安全与默认值

- 自动翻译默认关闭；不配置模型不发起请求。
- 不自动修改 Markdown。
- D3 CodeMirror 内联装饰未包含；计划在 2.3.x 以独立开关、隔离库验证后发布。

## 验证

- npm run build / npm test / npm run check / npm run release:check
- CI 检查 main.js 不含 @codemirror/* 或 @lezer/*。
- 运行时冒烟清单见 SMOKE.md；未记录视为未通过。

## 已知限制

- 行级诊断为主；除括号和未登记单位外，多数问题仍是近似范围。
- D2 不覆盖光标正在编辑的块；该缺口由 2.3.x D3 处理。
- 2.2.0 未单独发布，其内容并入本版本。
