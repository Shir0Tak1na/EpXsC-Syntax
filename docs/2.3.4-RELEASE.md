# 2.3.4 — SecretStorage 迁移

发布日期：2026-11-22

## 内容

- API Key 优先存入 Obsidian SecretStorage。
- 插件 data.json 只保存 secret 名称。
- 旧 provider.apiKey 自动迁移到 SecretStorage。
- 请求前通过 app.secretStorage.getSecret 解析。
- 无 SecretStorage 时保留旧文本输入框作为兼容降级。

## 条件

- Obsidian 1.11.4+ 提供 SecretStorage；当前 minAppVersion 1.15.1。
- SecretStorage 不防本机管理员或恶意插件；它解决 data.json 明文与同步泄露。
