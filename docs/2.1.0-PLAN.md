## 2.1.0 scope

### G2 多语言 T 块

    Flagros siro Ynen Flm
    > (zh-CN) 火焰穿过虚空。
    > (en) Flame crosses the void.

- 语言标签 BCP-47 风格，内部小写比较。
- 单行 > 文本 继续作为默认语言，兼容旧块。
- 同一语言重复：保留最后一条，lint 给 warning。
- 非法标签：忽略该行并提示。
- 2.1.0 仅一行一条译文，不做多行译文。

### G3 按语言显示

- 选择顺序：精确语言 → 基础语言（zh-CN 到 zh）→ fallback 设置 → 默认译文。
- 只显示当前语言对应的一条译文，不并排显示其他语言。
- 其他语言仍保留在源文件中，切换语言后重新显示。

### G4 缺译文状态

- 没有当前语言译文且自动翻译关闭：显示一行

      尚未翻译 / Untranslated

  只显示这一行，不回退 G 词注；G 与 T 的显示语义不能混。
- 自动翻译开启：先显示自动翻译中，完成后替换为参考译文，并带自动标记。
- 自动翻译失败：显示自动翻译失败（可重试），不抛异常、不写回正文。

### G5 自动翻译

- 默认关闭。
- 只处理 T 块，不处理 C/G 块，不翻译整篇笔记。
- 仅处理可见块；防抖、取消、超时、并发上限。
- 按 source + targetLang + model 缓存。
- 模型输出不写回 Markdown，只在渲染层展示。
- 自动译文必须与人工译文视觉区分。

### G6 作者参考翻译

- 独立命令：从中文生成 EpXs 参考。
- 输出面板展示：参考 EpXs、逐词、回译中文、lint、未知词。
- 只能复制或插入为参考块，绝不自动替换正文。
- 与 T 自动翻译共用 provider，但这是手动命令，不参与渲染。

### G7 设置页

四组：

1. 词库
   - 默认词库路径只读；
   - 自定义词库路径列表；
   - 导入本地 md/json；
   - 合并顺序：内置 → 默认 Vault → 自定义；
   - 冲突报告、词条数、重新载入。
2. 翻译
   - 启用自动翻译；
   - Provider 类型；
   - Base URL、endpoint、model、headers、API key、timeout、max tokens、temperature；
   - 目标语言、fallback；
   - 测试连接。
3. 显示
   - 当前语言；
   - 自动标记；
   - 尚未翻译行。
4. 诊断
   - 词库加载状态；
   - provider 状态；
   - 诊断报告。

## 2.1.0 non-goals

- 不做源码编辑器内联下划线。
- 不做 Codex 式补全、改写、悬浮建议。
- 不做云模型默认接入。
- 不做机器翻译自动写回笔记。
- 不做多行译文。

## 2.2.0 parked scope

- lint range 化（line、column、start、end）。
- tokenizer 输出 token offsets。
- 阅读视图 / Live Preview 红色虚线下划线 + tooltip。
- 源码编辑器 CodeMirror 装饰器。
- Codex 式辅助编写：补全、改写建议、语法解释、逐句诊断。
- 与 2.1.0 翻译层共用 provider 和设置。

## Core API

### src/core/ord/parse.js

- parseOrdLines(source, mode) → records
- parseTranslations(lines) → [{ lang, text, line }]
- normalizeLang(tag)
- pickTranslation(translations, lang, fallback)

### src/core/translation/request.js

- translationKey(source, targetLang, modelId)
- makeTranslationRequest(...)
- validateProviderConfig(config)

### src/core/lexicon/merge.js

- mergeDictionaries(base, overrides) → { dictionary, conflicts }
- 供默认词库与自定义词库合并。

### 稳定导出

- 现有 core/index.js 的导出不变。
- 新增 parseOrdLines、parseTranslations、pickTranslation、translationKey、mergeDictionaries。
- core 不引入 Obsidian、DOM、网络。

## Provider interface

    {
      id,
      label,
      validate(config),
      translate({ text, sourceLang, targetLang, context, signal })
    }

2.1.0 实现：

- openai-compatible（默认，支持本地 Ollama、LM Studio、其他网关）
- mock（测试）

失败必须返回带 code 的错误，由 service 降级，不向 renderer 抛异常。

## 防呆清单

- 自动翻译默认关；未配置 provider 时设置页显示未启用，不反复弹窗。
- 不把自动译文写回 Markdown。
- 不把自动译文当作人工译文；始终带自动标记。
- 不做 G/T 显示回退；缺译文只显示尚未翻译 / Untranslated。
- 同一块同一语言只请求一次；缓存命中不请求。
- 请求前检查长度、语言、provider、可见性。
- 超时、取消、失败都不阻塞阅读。
- 词库导入失败保留旧快照，并显示错误原因。
- 自定义词库覆盖有冲突报告；不静默覆盖。
- 设置迁移：旧版本无设置时使用默认值；不因缺少字段报错。
- 不记录 API key 到日志或诊断报告。

## Tests

- core：语言标签、默认译文、重复语言、非法标签、fallback 顺序。
- renderer：人工译文、自动状态、未翻译行、多语言切换。
- service：缓存、取消、超时、provider 失败、关闭自动翻译不请求。
- settings：默认值、持久化、非法配置、自定义词库合并。
- 集成：关闭自动翻译时零网络请求。
