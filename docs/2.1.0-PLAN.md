## F2 多语言 T 块

    Flagros siro Ynen Flm
    > (zh-CN) 火焰穿过虚空。
    > (en) Flame crosses the void.

规则：

- 语言标签按 BCP-47 子集校验：language 2-3 字母，可选 script 4 字母，region 2 字母或 3 数字，可选 variants；大小写归一化后再比较。
- 只在括号内容符合标签语法时按语言标签处理。
- 括号内容不符合标签语法，例如 > (他笑了) 你来了。，整行作为默认译文，不丢弃。
- 语言码 it、no、he 等合法但可能和自然括号相撞时，按标签处理；要写同样的默认译文开头，使用反斜杠转义：> \(it) 这是默认译文。
- 空译文忽略；不丢弃其他合法语言。
- 单行 > 文本 继续作为默认译文。
- 同一语言重复：最后一条生效，warning。
- 连续翻译行归属最近的源句；孤立翻译行 warning。
- 只做一次前导空白裁剪；正文中的括号、冒号、引号按原文保留，不按 Markdown 解析。
- 一行一条译文，不支持多行译文。

## F3 语言选择

    pickTranslation({
      translations,
      requestedLanguage,
      fallbackLanguage,
      defaultTranslation
    })

规则：

- requestedLanguage：精确匹配 → 基础语言（zh-CN 到 zh）。
- fallbackLanguage：同样只做精确 → 基础语言；只执行一次，不递归。
- defaultTranslation：旧版无标签 > 文本。
- 顺序：requested → requested base → fallback → fallback base → defaultTranslation。
- 没有匹配 → F4 未翻译状态。
- 只显示一条，不并排其他语言。

## F7 设置页与词库（2.1.0）

三组：

1. 词库
   - 默认路径只读；
   - 自定义路径列表，按列表顺序后者覆盖前者；
   - 导入 md/json；
   - 合并顺序：内置 → 默认 Vault → 自定义；
   - 冲突报告、词条数、重新载入。
2. 显示
   - 当前语言；
   - fallbackLanguage；
   - 尚未翻译行。
3. 诊断
   - 词库加载状态；
   - 诊断报告。

2.1.0 不显示 Provider 配置。2.2.0 再加翻译组。

词库身份：

- 以 word 为身份，不做 word+POS 的字段级合并。
- 同 word 不同 POS 属于冲突；后者整条覆盖，并记录类型冲突。
- 不合法词条不生效；旧快照保留。
- customPaths 内部按列表顺序后者覆盖前者。
- 词库重新载入后清空依赖词库的解析缓存。

## 2.2.0 — 联网层

### F5 自动翻译

- 默认关闭；只处理 T 块；只处理可见块；不翻译整篇笔记。
- 翻译单位是单个源句；每个源句独立记录和 sourceHash。
- sourceHash 对规范化后的单句取值：去首尾空白、连续空白折叠、换行统一；不折叠大小写。
- 同句同语言只允许一个有效请求；完成后缓存。
- 缓存键：

      {
        sourceHash,
        sourceLang,
        targetLang,
        lexiconVersion,
        providerFingerprint: {
          type, baseUrlOrigin, endpoint, model, promptVersion
        }
      }

- 不把 API key 或完整敏感配置放入缓存键。
- 内存 LRU（建议 256 条），不做持久化。
- 修改 provider、模型、promptVersion 或词库版本后，缓存和 in-flight 请求都失效。
- 维护 in-flight 表；同句同语言去重。
- 快速切换语言使用 generation token；旧响应不得覆盖新语言。
- 块卸载或不可见时取消；取消后不更新 DOM。
- 取消、超时、失败必须区分；取消不显示为失败。
- 自动译文始终带“自动”标记。

### 取消与传输

- Adapter 使用 Obsidian requestUrl 作为默认传输层。
- requestUrl 不保证 AbortSignal；2.1.0/2.2.0 的取消是逻辑取消：忽略结果、不更新 DOM，不承诺中断 HTTP。
- capability 标明 cancel: logical。
- 插件卸载时清空 in-flight 表、取消计时器、拒绝后续 DOM 更新。
- 以后若改用 fetch，必须单独评估本地 CORS 与安全边界。

### F6 作者参考

    TranslationService          → F5 阅读翻译
    ReferenceGenerationService  → F6 作者参考

- 手动命令，不参与 T 块渲染。
- 模型只返回 reference，可选返回 raw；不得让模型提供 lint、unknownWords、confidence 作为权威字段。
- Core 负责 tokenize(reference) → wordBreakdown → lint → unknownWords。
- 可选 backTranslation 由模型生成，但显示为“模型回译，非权威”。
- 输出：

      {
        reference,
        wordBreakdown: [{ text, gloss, offset }],
        backTranslation,
        lint: [{ code, line, column, message }],
        unknownWords: [{ text, line, column }]
      }

- 非法 JSON、缺字段、错误结构：显示可读错误，不写入正文。
- 只允许复制或用户确认后插入参考块；禁止自动替换正文。

### Provider contract

成功：{ ok: true, text }
失败：{ ok: false, error: { code, message, retryable } }
取消：{ ok: false, error: { code: 'CANCELLED' } }

能力：

    capabilities: {
      temperature, maxTokens, streaming, cancel: 'logical' | 'abort', structuredOutput
    }

Provider 负责 HTTP body、headers、响应解析和错误映射。Core 只产出 Provider 无关的 TranslationTask。

endpoint 规则：

- baseUrl 去掉尾部斜杠；
- endpoint 以 http 开头时视为完整 URL，忽略 baseUrl；
- endpoint 以 / 开头时与 baseUrl 拼接，避免重复斜杠；
- endpoint 不以 / 开头时补一个斜杠；
- 拼接后出现重复 /v1/v1/，配置报错；
- 非法 URL 不保存。

测试用例：

- baseUrl http://127.0.0.1:11434/v1 + endpoint /chat/completions
- baseUrl 以 /v1/ 结尾 + endpoint chat/completions
- endpoint 为完整 URL
- 空 baseUrl、非法协议、重复版本段

### 目标语言 auto

1. 适配层读取 Obsidian 界面语言；
2. 失败则 navigator.language；
3. 再失败则设置 fallbackLanguage；
4. 仍无法识别则视为无匹配语言，显示未翻译。

### 安全与隐私

- headers 中的 Authorization、Cookie、X-Api-Key 等在日志和诊断中脱敏。
- 错误信息不包含完整请求头或 apiKey。
- 非回环地址要求 HTTPS；http 只允许 localhost / 127.0.0.1 / ::1。
- 优先使用 Obsidian secret storage；不可用时设置页提示 data.json 明文风险。
- 首次启用自动翻译时说明发送内容；README 披露联网。
- 诊断报告只显示脱敏 endpoint 和 model。
- 测试包含请求头脱敏断言。

## Architecture

    Core
      纯解析、语言选择、缓存键、配置校验、翻译结果结构

    Services
      翻译调度、请求去重、缓存、取消、超时、降级、词库合并

    Providers
      请求构造、HTTP、响应解析、错误映射

    Adapter / Renderer
      Obsidian 生命周期、DOM、语言设置、用户交互

Core 不引入 Obsidian、DOM、网络。Provider 不直接操作 DOM 或 Vault。

### Core API

    src/core/ord/parse.js
      parseOrdLines(source)
      parseTranslations(lines)
      normalizeLang(tag)
      pickTranslation({ translations, requestedLanguage, fallbackLanguage, defaultTranslation })

    src/core/translation/request.js
      translationKey(...)

    src/core/lexicon/merge.js
      mergeDictionaries(base, overrides)

稳定导出：现有 core/index.js 不改旧名；新增上述纯函数。CLI 可复用解析和校验，不依赖网络。

## Renderer invariants

- 每个源句有稳定挂载点（索引或 sourceHash），异步译文只更新对应行。
- 沿用 refresh() → T/G 重渲染不变量。
- 语言切换、词库重载、provider 配置变化都走同一代次管理。
- 任何异步结果不得覆盖已卸载块或已切换语言的视图。
