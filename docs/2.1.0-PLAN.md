## 2.1.0 scope

### G2 多语言 T 块

    Flagros siro Ynen Flm
    > (zh-CN) 火焰穿过虚空。
    > (en) Flame crosses the void.

语言标签规则：

- 采用 BCP-47 风格：语言小写，script 首字母大写，region 大写；内部统一小写比较。
- 接受 zh、zh-Hans、zh-CN、en-US 等；非法标签忽略该行并 warning。
- 空译文不作为有效译文；不丢弃其他合法语言。
- 单行 > 文本 继续作为默认译文，兼容旧块。
- 同一语言出现多次：最后一条生效，warning。
- 2.1.0 一行一条译文，不支持多行译文。
- 分隔符后只做一次前导空白裁剪；正文中的其他字符、括号、冒号、引号按原文保留，不当作 Markdown 解析。
- 连续的翻译行归属于最近一个源句；没有源句的孤立翻译行单独记 warning。

### G3 按语言显示

- 精确语言 → 基础语言（zh-CN 到 zh）→ 配置 fallback → 默认译文。
- 只做一次 fallback，不递归，避免循环配置。
- fallbackLanguage 与 defaultTranslation 是两个独立概念：
  - fallbackLanguage 是用户指定的备用语言；
  - defaultTranslation 是旧版无标签 > 文本。
- 只显示当前语言对应的一条；不并排显示其他语言。
- 无匹配且自动翻译关闭：进入 G4 的“尚未翻译”状态。

### G4 缺译文状态

统一状态组件，不在各渲染路径里写死：

    { kind: 'human', lang, text }
    { kind: 'auto', lang, text }
    { kind: 'auto-pending', lang }
    { kind: 'auto-failed', lang, error }
    { kind: 'untranslated' }

- 自动翻译关闭或缺译文：显示一行 尚未翻译 / Untranslated。
- 不调用 G 词注，不把 G 词注当作 T 译文。
- 人工译文永远优先于自动译文。
- 自动失败不覆盖人工译文；不显示过期的自动翻译中状态。
- 不自动往 Markdown 插入 > 行。

### G5 自动翻译

- 默认关闭；只处理 T 块，不处理 C/G 块，不翻译整篇笔记。
- 只处理可见块；防抖、取消、超时、并发上限。
- 不写回 Markdown，只在渲染层展示。
- 自动译文始终带“自动”标记。
- 人工译文存在时不请求自动翻译。
- 同块同语言只允许一个有效请求；完成后缓存。

缓存键：

    {
      sourceHash,
      sourceLang,
      targetLang,
      providerFingerprint: {
        baseUrlOrigin, endpoint, modelId, promptVersion
      }
    }

- 不把 API key 或完整敏感配置放进缓存键。
- 2.1.0 只做内存缓存，LRU 上限建议 256 条；不做持久化。
- 修改 provider 配置、模型或 promptVersion 后，相关缓存失效。
- 同时维护 in-flight 请求表，避免重复请求。
- 快速切换语言时使用 generation token，过期响应不得覆盖新语言。
- 块卸载或不可见时取消请求；取消后不更新 DOM。
- 失败仅降级到 auto-failed，不破坏原文和人工译文。

### G6 作者参考翻译

G6 与 G5 分开：

    TranslationService          → G5 自动阅读翻译
    ReferenceGenerationService  → G6 中文到 EpXs 参考

- G6 是手动命令，不参与 T 块自动渲染。
- 必须读取当前词库快照与语法约束；模型输出不是权威语法结果。
- 结构化输出：

      {
        reference,
        wordBreakdown,
        backTranslation,
        lint,
        unknownWords,
        confidence
      }

- 流程：词库快照 → 提示词 → 模型生成 → Core tokenize/lint → 标记未知词与不合法结构 → 面板展示 → 作者复制或插入参考块。
- 绝不自动替换正文。
- 模型输出非法 JSON、缺字段或结构错误时，显示可读错误，不写入正文。

### G7 设置页

1. 词库
   - 默认路径只读；
   - 自定义路径列表；
   - 导入 md/json；
   - 合并顺序：内置 → 默认 Vault → 自定义；
   - 冲突报告、词条数、重新载入。
2. 翻译
   - 启用自动翻译；
   - Provider 类型（openai-compatible）；
   - baseUrl、endpoint、model、headers、apiKey、timeout、maxTokens、temperature；
   - 目标语言、fallback；
   - 测试连接。
3. 显示
   - 当前语言；
   - 自动标记；
   - 尚未翻译行。
4. 诊断
   - 词库状态；
   - provider 状态；
   - 诊断报告。

设置结构建议：

    {
      lexicon: {
        customPaths: [],
        mergeOrder: ['builtin', 'vault', 'custom']
      },
      translation: {
        enabled: false,
        provider: {
          type: 'openai-compatible',
          baseUrl: '',
          endpoint: '/chat/completions',
          model: '',
          headers: {},
          apiKey: '',
          timeoutMs: 30000,
          maxTokens: 2048,
          temperature: 0.3
        },
        fallbackLanguage: '',
        targetLanguage: 'auto'
      },
      display: {
        autoBadge: true,
        showUntranslated: true
      }
    }

endpoint 规则：

- endpoint 以 http 开头时视为完整 URL；
- 否则与 baseUrl 拼接，避免重复 /v1/chat/completions；
- 设置页显示最终解析结果。

Provider 配置安全：

- API key 只保存在插件设置，不进入日志、诊断报告和错误堆栈；
- 诊断只显示脱敏 endpoint/model；
- 修改 provider 后清除相关翻译缓存；
- 非法配置保留上次有效值，不覆盖已保存配置；
- 本地地址默认允许 http://127.0.0.1 与 localhost；远程地址由用户明确填写。

## 2.1.0 non-goals

- 不做源码编辑器内联下划线。
- 不做 Codex 式补全、改写、悬浮建议。

- 不做多行译文。
- 不做字段级词库合并。

## Architecture

    Core
      纯解析、语言选择、缓存键、配置校验、翻译结果结构

    Services
      翻译调度、请求去重、缓存、取消、超时、降级、词库合并

    Providers
      请求构造、HTTP、响应解析、错误映射

    Adapter / Renderer
      Obsidian 生命周期、DOM、语言设置、用户交互

Core 不引入 Obsidian、DOM、网络。Provider 不直接操作 DOM 或 Vault。

### Core API

    src/core/ord/parse.js
      parseOrdLines(source, mode)
      parseTranslations(lines)
      normalizeLang(tag)
      pickTranslation(translations, lang, fallback)

    src/core/translation/request.js
      translationKey(...)
      makeTranslationRequest(...)
      validateProviderConfig(config)

    src/core/lexicon/merge.js
      mergeDictionaries(base, overrides)

稳定导出：现有 core/index.js 不改旧名；新增上述纯函数。CLI 可复用解析和校验，不依赖网络。

### Provider contract

    成功：{ ok: true, text }
    失败：{ ok: false, error: { code, message, retryable } }

能力声明：

    capabilities: {
      temperature, maxTokens, streaming, cancel, structuredOutput
    }

2.1.0 实现 openai-compatible 与 mock。Provider 不抛裸异常；service 负责映射和降级。

## Lexicon merge rules

- 顺序：内置 1 → 默认 Vault 2 → 自定义 3；后者整条覆盖前者。
- 2.1.0 不做字段级合并。
- 冲突报告必须区分：完全相同、定义不同、类型不同、不合法词条、不兼容版本。
- 导入失败保留旧快照，并在设置页显示原因。
- 空文件、格式错误、缺 section 不生效。
- 词库重新载入后清空依赖词库的解析缓存，但不影响已有人工译文。

## Tests

| 模块 | 必须覆盖 |
| :---: | :--- |
| G2 | 空译文、特殊字符、BCP-47 规范化、重复标签、非法标签 |
| G3 | 精确/基础/fallback/默认顺序；无匹配；不递归 |
| G4 | 人工与自动并存；自动失败；未翻译状态；不混 G |
| G5 | 快速切语言过期响应、重复触发去重、同模型不同 Provider、缓存失效、LRU、取消后不更新 |
| G6 | 非法 JSON、缺字段、未知词、lint 错误、错误回译 |
| Settings | 旧配置迁移、缺字段、非法配置、密钥脱敏 |
| Provider | 超时、连接失败、认证失败、非法响应 |
| 集成 | 自动翻译关闭时零网络请求；切换语言/刷新/重开文件均显示统一未翻译状态 |

额外断言：

- 没有写回 Markdown；
- 没有意外网络请求；
- 没有丢失原文；
- 没有把 G 词注当 T 译文；
- 失败后原有渲染不损坏。

## Delivery phases

1. 多语言基础：G2 解析 → G3 选择 → G4 状态；不依赖网络。
2. 词库与配置：G7 词库导入 → Provider 配置 → 设置持久化。
3. 自动翻译：Provider → TranslationService → 缓存/取消 → Renderer 集成。
4. 作者参考：G6 → 结构化输出 → Core lint → 参考面板。
5. 集成验收：全量测试 → 文档 → 2.1.0 发布。

## Release gate

- 构建、check、测试、release:check 全部通过。
- README、CHANGELOG、ARCHITECTURE、设置文档更新。
- manifest 2.1.0、versions 映射、release assets 三件套。
- 一天最多一个 Release；本次不提前发布。
