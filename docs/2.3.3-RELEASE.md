# 2.3.3 — 精确诊断与可选相邻上下文

发布日期：2026-11-22

## 内容

- D3 诊断增加 token 级精确下划线，整行仍保留红/橙提示。
- D4.2 新增“发送相邻句”开关，默认关闭。
- 发送前确认框显示实际发送的相邻范围。
- 相邻句只取块外紧邻的一行前文/后文，最多各 300 字符。

## 默认值

- diagnostics.editorDecorations: false
- assistance.enabled: false
- assistance.sendAdjacent: false

## 验证

- npm test / build / check / release:check
- jsdom D3/ghost smoke
- D4.2 prompt fixture

## 已知限制

- API Key 仍保存在 data.json（Secret Storage 未实现）。
- D3 仍为实验功能。
