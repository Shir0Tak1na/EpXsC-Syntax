# 2.2.0 — 可选联网翻译层

2.2.0 为 EpXsC Syntax 增加可选的 OpenAI-compatible 翻译能力。默认关闭，不配置模型时插件仍是无网络阅读工具。

## 新增

- T 块缺当前语言译文时，可选用本地/兼容端点生成译文。
- 自动翻译使用源句词典、语法摘要和少量已验证译例；人工译文优先。
- 内嵌缓存、in-flight 去重、超时和逻辑取消。
- “从中文生成 EpXs 参考”命令：JSON 输出、逐词、未知词和 lint 校验；插入必须手动确认。
- 设置页支持 Base URL、Endpoint、Model、Headers、API Key、超时、maxTokens、temperature、连接测试和语法上下文文件。
- 非回环地址强制 HTTPS；请求头/URL/异常文本脱敏。

## 安全与默认值

- 自动翻译默认关闭；关闭时不创建服务、不发送请求、不加载模型。
- 不自动修改 Markdown。
- 模型只是参考；未知词或 lint error 会阻止“插入参考块”。

## 验证

`npm run build`、`npm test`、`npm run check`、`npm run release:check` 通过。

## 已知限制

- F5 会按源句翻译；源句本身有语法歧义时，译文不能替代语法检查。
- F6 的 7B 本地模型仍可能给出不理想表达，必须人工核对。
- 真正的红色虚线下划线和结构诊断在 2.3.0。
